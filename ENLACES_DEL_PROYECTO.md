# Estación de Servicio — Kodigo

## Repositorio GitHub
https://github.com/enriqueramoscastillo1-web/estacion-de-servicio

## Aplicación publicada en Vercel
https://estacion-de-servicio.vercel.app/

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Vite

## Funcionalidades
- Galería interactiva de productos.
- Filtros por categoría y precio.
- Selección de productos y cálculo automático del total.
- Simulación de despacho de combustible por dólares y galones.

## Ejecución del proyecto
1. Ejecutar pnpm install.
2. Ejecutar pnpm dev.
3. Abrir la dirección local que indique Vite.
