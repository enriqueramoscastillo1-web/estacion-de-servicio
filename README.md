# ⛽ Galería Interactiva de Productos

## Vercel: https://estacion-de-servicio.vercel.app
## Estación de Servicio

### Descripción

Aplicación web interactiva desarrollada como parte
del Bootcamp de Desarrollo Web de Kodigo.

El proyecto simula una estación de servicio que
cuenta con dos departamentos principales:

1. Pista de combustibles.
2. Tienda de conveniencia.

Los usuarios podrán visualizar productos,
consultar precios y agregarlos a un carrito.

## Objetivo general

Desarrollar una galería interactiva de productos
utilizando HTML5, CSS3 y JavaScript, aplicando
la manipulación del DOM y eventos.

## Funcionalidades

- Visualización de productos.
- Selección de departamentos.
- Filtrado por categorías.
- Carrito de compras.
- Cálculo automático de totales.
- Eliminación de productos.
- Diseño responsive.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Vite
- Git y GitHub

## Estructura

- index.html: estructura HTML.
- src/main.js: lógica de JavaScript.
- src/style.css: estilos visuales.
- AGENTS.md: reglas del proyecto.
- DESIGN.md: documentación del diseño.

## Ejecución

Instalar dependencias:

pnpm install

Iniciar servidor:

pnpm dev

Abrir la dirección local que indique Vite.

## Metodología

El proyecto se desarrollará por etapas:

1. Análisis de requerimientos.
2. Diseño del algoritmo.
3. Elaboración del diagrama de flujo.
4. Creación de la interfaz.
5. Programación en JavaScript.
6. Pruebas de funcionamiento.
7. Documentación y entrega.
